Rules in CSS,

These rules decide that in which priority, CSS will apply its styles to.

  1. Important: This will be prioritized the most.
    Syntax:
    • body {background: red !important}

  2. Specificity: CSS priorites the selector which is more specified, rather than a general one.
    Example:
    • nav > ul > li {} will be priotized over just li {}, if you want to target an element inside a navbar.

  3. Last Rule: CSS prioritizes the selector which is written in the last in code.
    Example:
    • nav > ul > li {} will be priotized over just li {}, if you want to target an element inside a navbar.


Inheritance in CSS

Inheritance in CSS states that how some values of properties are passed down to its children automatically.
